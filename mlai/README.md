# 🌌 Nature Analyzer AI Pro

**Next-Generation Neural Scene Intelligence Engine**

Nature Analyzer AI Pro is a premium high-fidelity image classification system designed to analyze and categorize natural landscapes and satellite imagery with state-of-the-art precision. Developed with a focus on both technical excellence and a cutting-edge "Cyber-Luxe" aesthetic.

---

## ✨ Features

- **Advanced CNN Core**: Powered by a robust Deep Learning model (`best_cnn_model.keras`) optimized for scene recognition.
- **Cyber-Luxe UI**: A premium user experience featuring:
  - **Glassmorphism**: Translucent panels with deep-space backdrop filters.
  - **Dynamic Animations**: Floating hero section and animated gradient text.
  - **Neon Accents**: High-tech visual feedback and interactive glows.
- **Real-Time Analysis**: Instant telemetry data processing and spectral landscape classification.
- **Detailed Analytics**: Full probability distribution breakdown for all supported semantic classes.

---

## 🚀 Supported Semantic Landscapes

The system is trained to recognize the following high-level categories:
- 🏢 **Buildings**: Urban structures and architectural elements.
- 🌲 **Forest**: Dense vegetation and woodland areas.
- ❄️ **Glacier**: Ice formations and polar landscapes.
- 🏔️ **Mountain**: High-altitude peaks and ranges.
- 🌊 **Sea**: Coastal regions and open water bodies.
- 🛣️ **Street**: Infrastructure and transportation corridors.

---

## 🛠️ Technology Stack

- **Framework**: [Streamlit](https://streamlit.io/)
- **Core Intelligence**: [Keras 3](https://keras.io/) (Torch Backend)
- **Neural Processing**: [PyTorch / Torch](https://pytorch.org/)
- **Image Processing**: [Pillow (PIL)](https://python-pillow.org/)
- **Mathematical Engine**: [NumPy](https://numpy.org/)

---

## ⚙️ Installation & Usage

### 1. Clone the environment
Ensure you have Python 3.9+ installed on your system.

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Launch the Intelligence Core
```bash
streamlit run app.py
```
